CSV FILE FORMAT

Your CSV file must have exactly 5 columns:

Question,Correct Answer,Wrong Answer 1,Wrong Answer 2,Wrong Answer 3

Required Structure:

  • Header Row: First row must be the header (will be skipped)
  • Column 1: The question text
  • Column 2: The correct answer
  • Columns 3-5: Three wrong answers (all required)
  • All 5 columns required: Every row must have exactly 5 fields

Basic Example:

What is the capital of France?,Paris,London,Berlin,Madrid
What is 2 + 2?,4,3,5,6
Who painted the Mona Lisa?,Da Vinci,Picasso,Van Gogh,Monet

Multi-Line Content (Code Examples):

  • Wrap in double quotes: Any field with commas, newlines, or quotes must be wrapped in double quotes
  • Press ENTER: Inside quotes, press ENTER/Return to add line breaks
  • No line limit: Use as many lines as needed for code snippets
  • Indentation preserved: Spaces and tabs are kept as-is
"What does this code print?
for i in range(3):
  print(i)",0 1 2,Error,3 2 1,0 1

Escaping Special Characters:

  • Quotes inside quotes: Use "" (two double quotes) to represent a literal quote
  • Commas: Must wrap field in quotes if it contains commas
  • Example: "He said ""Hello"",world",correct,wrong1,wrong2,wrong3
"What is the output?
String s = ""Hello"";
System.out.println(s);",Hello,Compilation error,"""Hello""",null

Common Mistakes to Avoid:

  • Missing fields: Each row MUST have exactly 5 comma-separated values
  • Unmatched quotes: Every opening quote must have a closing quote
  • Wrong escaping: Use "" not \" for quotes inside quoted fields
  • Missing header: First row must be the header row
  • Trailing commas: Don't add extra commas at the end of rows

Advanced: Java Text Blocks and Special Cases:

  • Triple quotes (Java text blocks): Use """""" (six quotes) to represent """ in code
  • Escape sequences: Use \n for newlines in answers, \t for tabs
  • Unicode characters: Fully supported (€, ♥, etc.)
  • Empty fields: Use empty string between commas: ,,, (if intentional)

Validation: The app will reject files with incorrect field counts or formatting errors. Check that every row has exactly 5 fields!

HOW TO PLAY

Game Format:

  • Configure questions per round (4, 10, 20, or 50)
  • Set seconds per question (5, 10, 30, 60, or 108)
  • Total time = questions × seconds per question
  • Questions are randomly selected from your CSV file

During Each Round:

  • Select one answer for each question
  • Click SUBMIT ANSWERS when ready
  • See your results with correct answers highlighted in green
  • View your round percentage and cumulative score

Scoring:

  • Round score shows your percentage for the current round
  • Cumulative score tracks your total performance across all rounds
  • Number of questions answered is displayed with cumulative score

Reset Score:

  • Click "BACK TO MENU" to return and reset all scores to 0
  • Upload a new CSV file to start fresh with different questions

Continue Playing: Press ENTER or SPACE to start the next round with new random questions!
